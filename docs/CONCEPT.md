# Visual direction record

Reference: [`concept.png`](concept.png). Generated with the built-in image generation
tool, then implemented using live HTML/CSS and procedural Three.js geometry.
No generated bitmap is loaded by the artwork. Astra reviewed the experience and
implementation; source and browser findings were used to refine the result.

## Generation prompt

Use case: ui-mockup / creative direction reference. Create one polished triptych
concept board for BROWSERCEPTION, an interactive browser art piece. Three equal
landscape panels stacked vertically, each wide 16:9, clean readable composition.
Panel 1 is the actual ordinary editorial studio homepage, pale paper #e9e8e2,
black oversized condensed sans-serif BROWSER on first line, CEPTION on second,
an outline long arrow to the right, fine graphite grid rules, small black
BROWSERCEPTION wordmark upper left, 'An independent experiment in perception.'
upper right, a tiny red square, slim footer 'THE BROWSER IS NOT A WINDOW.' on
left, 'IT IS A WORLD.' on right. Central lower black rectangular ENTER button
with arrow. Smaller editorial subtitle 'A study in digital space.' near right.
It must look like a precise sophisticated Swiss experimental studio site, no
visible 3D, no rounded cards, no sci-fi dashboard. Panel 2: same typography has
physically peeled into monumental extruded charcoal letter architecture within
huge paper-white void; three massive nested rectangular frame corridors tilted
in impossible perspective, precise graphite grid lines, paper panels with
editorial text floating, cinematic shadows, extremely large scale, restrained
red thread. Panel 3: huge silent monochrome brutalist cathedral formed from
letters and rectangular window frames, one small black desktop monitor on a
white pedestal at center, original exact homepage visible inside monitor.
Visual emphasis is coherent surreal typography, extreme scale contrast,
geometry that can be built natively in Three.js, not photoreal assets. All UI
typography and controls implemented in HTML/CSS, all architecture procedural
Three.js. No gradients, neon, planets, decorative particles, abstract chrome
blobs. This is a reference for a five-scene continuous artwork: ordinary page,
fracture, descent, revelation, loop. Include all controls only on first panel:
ENTER, Sound off, Reduce motion. No invented nav links or badges.
