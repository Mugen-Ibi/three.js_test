# Local typeface asset

`helvetiker_bold.typeface.json` is copied unchanged from the official `three@0.180.0` npm package (`examples/fonts/helvetiker_bold.typeface.json`). Newer Three.js npm packages no longer ship the font directory. Vendoring the exact existing font keeps offline use and the original lettering rather than changing the visual design.

SHA-256: `bd68159ee0b8d10fe24b9daa2e32f19686f9d8269a79dc8d44203a66298bfa2f`.

The existing Helvetiker license is retained at [`public/licenses/helvetiker.txt`](../../public/licenses/helvetiker.txt). No font network request is made at runtime.
